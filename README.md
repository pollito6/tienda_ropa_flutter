# Tienda de Ropa Flutter

Esta es una aplicación móvil de ejemplo para una tienda de ropa, construida con Flutter. Permite mostrar un catálogo de productos y está lista para expandirse con carrito de compras, detalles de producto y más.

## Estructura inicial
- `lib/main.dart`: Punto de entrada de la app.
- `lib/models/product.dart`: Modelo de producto.
- `lib/screens/catalog_screen.dart`: Pantalla principal con el catálogo.
- `assets/images/`: Imágenes de ejemplo para productos.

## Cómo ejecutar
1. Asegúrate de tener Flutter instalado.
2. Ejecuta `flutter pub get` para instalar las dependencias.
3. Ejecuta `flutter run` para iniciar la app en un emulador o dispositivo Android.

¡Listo para personalizar y expandir!
